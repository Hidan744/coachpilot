# CoachPilot AI

Мобильный AI-помощник футбольного тренера: подготовка тренировки → проведение с телефона → отчёт → следующая тренировка. Рынок — Россия и СНГ.

| Каталог | Что внутри |
|---|---|
| `app/` | Flutter-приложение (iOS/Android), local-first: SQLite (Drift) + фоновая синхронизация |
| `backend/` | API на FastAPI + PostgreSQL: авторизация, синхронизация, AI-генерация, каталог упражнений |
| `docs/` | Архитектура, решения, план этапов |

## Быстрый старт backend

```bash
cd backend
python3 -m venv .venv && .venv/bin/pip install -r requirements-dev.txt
cp .env.example .env            # при необходимости поправьте CP_DATABASE_URL
.venv/bin/alembic upgrade head
.venv/bin/uvicorn app.main:app --reload
# документация API: http://localhost:8000/docs
```

Или целиком в Docker: `docker compose up --build` (API на :8000, Postgres на :5432).

Тесты: создайте БД `coachpilot_test` и запустите `.venv/bin/pytest`
(адрес БД задаётся переменной `CP_DATABASE_URL`).

## Статус этапов

- [x] 0. Каркас: репозиторий, Docker, CI
- [x] 1. Backend-ядро: авторизация, модель данных, синхронизация, изоляция данных, экспорт/удаление аккаунта
- [x] 2. Приложение: основа + офлайн (вход, онбординг, локальная БД, outbox, синхронизация, конфликты)
- [x] 3. Команда, игроки, посещаемость, оценки навыков
- [x] 4. Библиотека: 81 упражнение (встроено, работает офлайн), поиск, фильтры, избранное, свои упражнения, редактор схем
- [x] 5. Планы тренировок и AI: мастер, редактор плана, проверка длительности, AI с валидацией и автопочинкой, офлайн-генерация по правилам
- [x] 6. Режим занятия: таймер по меткам времени (переживает сворачивание и перезапуск), пауза, ±1 мин, пропуск, заметки, офлайн
- [x] 7. Отчёт (AI-оформление с псевдонимизацией имён, предложения AI отдельно) и история занятий
- [x] 8. Аналитика и ошибки (своё хранилище), защита входа, экспорт данных, продакшен-развёртывание, CI со сборкой APK/iOS и e2e

Подробности — в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Дополнительно

- Анимация схем: стрелки по шагам, кнопка ▶ показывает движение игроков и мяча
- Импорт игроков из Excel, Word, CSV; импорт упражнений из Word, Excel, TXT с разбором описания (AI или правила)
- Клубный стиль (ФК Амкар), демо-режим без регистрации, web-версия на GitHub Pages
- Календарь сезона: матчи (вручную или списком из Excel/Word/текста), регулярные тренировки всех команд
  по дням недели и времени, переход от тренировки в календаре к её плану
- Тактическая доска: расстановки 11×11…5×5, состав по позициям, перетаскивание фишек, рисование пальцем,
  стрелки по шагам с анимацией, замены со скамейки, поворот поля, доска на матч
- Индивидуальные планы развития игроков на неделю, месяц и сезон (цели и задания с отметкой выполнения)
- Родителям: сообщения тренера по темам (питание, психология, доп. тренировки…), страница игрока по ссылке
  без входа (посещаемость, оценки, план, расписание), готовый текст для мессенджера
- Профиль игрока: общий балл, радар навыков, динамика, вкладки ОФП, развитие, статистика, родителям
- Статистика матчей (голы, передачи, удары, отборы, карточки, сейвы, оценка), итоги сезона, загрузка из Excel
- Тесты ОФП с баллами по возрасту и радаром, программа развития на 4–6 недель «сейчас → цель»
- Дашборд команды, отчёт о прогрессе в PDF, выгрузка отчётности в Excel, тренерский штаб
- Редактор схем: движение игрока по точкам, мяч закреплён за игроком, пас касанием партнёра
