# Безопасность и персональные данные

CoachPilot обрабатывает данные детей. Ниже — что уже сделано технически и что нужно проверить юристу.
Наличие галочки согласия не доказывает соответствие закону: это решает юрист по 152-ФЗ.

## Сделано в коде

| Требование | Как реализовано |
|---|---|
| Минимизация данных | Обязательно только имя игрока; медицинских полей нет. Отметка «травма» в посещаемости — без диагноза |
| Разграничение доступа | Каждая запись принадлежит владельцу (`owner_id`). Сервер проверяет владельца при чтении и записи, а также ссылки на чужие команды, игроков и тренировки (тесты в `test_sync.py`) |
| Аутентификация | Пароли — argon2; access-токен на 30 минут; refresh-токен с ротацией; ограничение попыток входа и регистраций |
| Проверка прав на сервере | Клиенту не доверяем: схема данных проверяется на сервере (Pydantic), лишние поля отбрасываются |
| Ключи и секреты | AI, Telegram и оплата — только в переменных окружения сервера; в клиенте и сборке их нет |
| Согласие пользователя | При регистрации фиксируются согласие и версия текста (`consent_version`) |
| Согласие родителя | Отметка в карточке игрока: кто дал, когда, где хранится документ. Без неё сервер не создаёт ссылку для родителей несовершеннолетнего (409) |
| Ссылка для родителей | Видна только карточка одного игрока, только то, что тренер отметил «видно родителям». Ссылку можно отозвать |
| Журнал действий | Регистрация, вход, выгрузка данных, ссылки родителям, смена тарифа, Telegram — таблица `audit_log`, пользователь видит свой журнал |
| Экспорт и удаление | Выгрузка всех данных (`/account/export`, JSON) и удаление аккаунта с каскадным удалением данных |
| Сроки хранения | `python -m app.maintenance purge`: удалённые записи — через 180 дней, журнал AI — через 365, журнал действий — через 1095 (настраивается) |
| AI и данные | Имена игроков заменяются на «игрок» перед отправкой в модель (тест `test_player_names_not_sent_to_ai`) |
| Видео | Видео в приложение не загружается — хранится ссылка; доступ к файлу определяется хостингом клуба |

## Не сделано / требует решения

- Аккаунты родителей и игроков с привязкой к ребёнку — следующий этап (сейчас родитель видит данные по ссылке без входа).
- Шифрование резервных копий и журнал доступа к БД — настраиваются на уровне инфраструктуры.
- Оператор и место хранения: сервер и БД нужно разместить в России (см. `DEPLOY_RU.md`).

## Вопросы юристу

1. Кто оператор ПД: тренер, школа или разработчик? Нужен договор поручения обработки (ч. 3 ст. 6 152-ФЗ)?
2. Форма согласия законного представителя для детей до 14 лет и для 14–18 лет; хватает ли отметки тренера о бумажном согласии?
3. Нужно ли уведомление Роскомнадзора об обработке ПД?
4. Отнести ли отметки «травма» и результаты тестов ОФП к специальным категориям (сведения о здоровье)?
5. Сроки хранения данных ушедших игроков и порядок уничтожения.
6. Передача обезличенных текстов отчётов в AI-сервис (YandexGPT, GigaChat): нужна ли отдельная оговорка в согласии?
7. Трансграничная передача: исключить сервисы вне России (в том числе CDN и шрифты).
8. Политика обработки ПД и пользовательское соглашение для публикации.
